# Unchanged newsroom tuning drafts

These are all 72 drafts from the [registered 12-packet tuning cohort](../../tuning-design.json).
Each folder contains GPT-6 Astra and Claude Sonnet 5 responses under `bare-task`,
`full` and `compact` instructions. Each draft was generated independently from
the same reporting packet; these are not before-and-after edits.

The stories, reporting records and events are fictional. They are not real news,
medical or investment advice, human-written reference articles, or proof that a
recipe improves writing. No draft was selected or rewritten to make a condition
look better. Files preserve the captured response exactly, including any markup
or unwanted commentary.
